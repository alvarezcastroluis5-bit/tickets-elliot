# Consulta de Tickets Elliot

Página web para que los clientes puedan consultar sus tickets del sorteo ingresando su número de WhatsApp.

## Archivos del proyecto

- `index.html`: página principal.
- `README.md`: información del proyecto.

## Cómo usar

1. El cliente ingresa su número de WhatsApp.
2. Presiona el botón "Consultar tickets".
3. La página muestra sus tickets asignados.

## Importante

El archivo principal debe llamarse exactamente:

`index.html`

Así GitHub Pages podrá abrir la página automáticamente.
